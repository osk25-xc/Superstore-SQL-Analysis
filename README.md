# Superstore Sales Analysis | SQL & Python

A portfolio project exploring retail order data to answer practical sales, profitability, product, customer, and regional performance questions.

## Business Objective
Turn transactional sales data into decision-ready summaries that help identify where revenue and profit are coming from and how performance changes over time.

## Questions Explored
- How do sales and profit vary by region and category?
- Which products and customers contribute most to sales?
- How does monthly sales performance change?
- What is the average order value?
- Which regions or product groups warrant further investigation?

## Tools
- SQL / SQLite
- Python, Pandas, NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Analysis Workflow
1. Inspect the dataset and validate fields.
2. Query sales, profit, category, region, customer, and monthly trends.
3. Summarize results with aggregations and ranking logic.
4. Visualize selected findings for easier interpretation.

## Repository Contents
- `data/` — dataset and local database, where included
- `notebooks/` — analysis notebook
- `sql/` — reusable analysis queries
- `visuals/` — charts generated by the analysis
- `requirements.txt` — Python dependencies, if applicable

## Run the Project
1. Clone or download this repository.
2. Install dependencies listed in `requirements.txt`, if present.
3. Open the notebook in Jupyter, or run the SQL scripts in a compatible SQLite environment.
4. Update file paths if your local folder structure differs.

## Business Value
This project demonstrates how SQL aggregations and Python visualizations can support routine sales reporting and help stakeholders investigate performance differences. Findings should be interpreted in the context of the dataset; no real-company outcomes are claimed.

## Skills Demonstrated
Data cleaning and exploration · SQL querying · KPI analysis · Trend analysis · Ranking · Data visualization · Business communication
